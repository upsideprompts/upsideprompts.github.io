### Fixed Sorting Bug in AI Hardware Stock Dashboard
- **File**: hwdeck/index.html
- **Problem**: Monthly return column and 3-month change column weren't sorting properly
- **Root causes identified**:
  1. `sortStocks()` function used `event.target` without the event being passed as a parameter
  2. `case 'change':` had a `break` statement instead of returning the sort comparison
  3. Missing `case 'month-asc':` handler for ascending sort
  4. Button onclick handlers weren't passing the button element for active state
- **Fixes applied**:
  - Added `buttonElement` parameter to `sortStocks()` function
  - Fixed `change` case to properly return sort comparison
  - Added `case 'change-asc':` and `case 'month-asc':` handlers
  - Updated all button onclick handlers to pass `this` as second parameter
- **Result**: All sort buttons now work correctly
