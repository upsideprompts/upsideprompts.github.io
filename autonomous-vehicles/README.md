# AMD Autonomous Vehicles Microsite

A modern, responsive web microsite showcasing AMD technology for autonomous vehicles.

## Features

- **Modern Design**: Dark theme with AMD-inspired color scheme (red, cyan, white)
- **Responsive Layout**: Works on mobile, tablet, and desktop
- **Video Integration**: Embedded links to relevant AMD YouTube content
- **Technology Showcase**: Highlights AMD processors and AI solutions for autonomous driving

## Files

- `index.html` - Main microsite (self-contained, no external dependencies)

## Quick Start

Simply open `index.html` in any web browser. No server required.

## Content Summary

The microsite features:

1. **Hero Section**: Introduction to AMD's autonomous vehicle technology
2. **Video Cards**: Three AMD YouTube videos with 3-sentence summaries and direct links
3. **Technology Specs**: Key AMD technologies for autonomous vehicles

## Videos Featured

1. AMD Ryzen™ AI Halo processors
2. Enterprise AI solutions with EPYC CPUs and Instinct GPUs
3. AMD AI developer events and software stack (ROCm, PyTorch)

## Hosting

To deploy this microsite:

- Upload `index.html` to any web server
- Or serve directly from GitHub Pages, Netlify, Vercel, etc.
- No build process required - it's a single HTML file
